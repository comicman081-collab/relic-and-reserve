# R3 Authored Case Remediation Roadmap

Status date: 2026-08-24 (Asia/Seoul)

This roadmap records the implementation order agreed during the GPT web design review. It is a source milestone plan, not a release declaration. Automated PASS does not mean the game is complete.

## Permanent release hold

Do not create, rebuild, modify, or package `.exe`, `.pck`, `.zip`, `.7z`, or `.rar` artifacts until the user gives a new explicit instruction. Existing Manus R2 Windows artifacts and archives remain read-only references.

## Runtime authority contract

The playable investigation chain is:

`artifact inspection -> evidence ledger -> cross-source validation -> hypothesis -> cited report -> authoritative resolution -> appraisal/listing/auction`

Player-facing appraisal and bidder behavior may use disclosed conclusions, confidence, condition, provenance evidence, and listing terms. They must not read hidden truth to change the quote. Deprecated caller-supplied case outcomes and caller-supplied commission quality fail closed.

Case resolution records two separate dimensions:

- **Conclusion accuracy:** whether the selected hypothesis matches the authored canonical conclusion.
- **Report substantiation:** whether cited, discovered evidence supplies sufficient net support from independent source groups and satisfies required-source rules.

## Next implementation order

Before each further batch advances:

- all cases use the generic normalizer, resolver and illustrated dossier with no case-ID gameplay/UI branch;
- a single source cannot reach credible or masterful;
- authored risks preserve a majority safe route and clearly differentiated tools;
- hidden canonical truth cannot change pre-discovery public state or the policy's next action;
- same seed plus the same visible action sequence remains deterministic;
- save interruption and legacy issued-artifact identity tests remain green;
- actual Korean and English 1280x720 captures receive original-resolution human review.

An authored tranche PASS is still not a declaration that the full game is complete and does not lift the Windows/archive release hold.

- Full campaign balance runs covering competent, ordinary-mistake, low-cash, misleading/high-risk and museum/integrity paths.

Only after those milestones and a new explicit user instruction may Windows build/runtime/package verification begin. Until then Windows QA and release hashes remain **HELD / UNVERIFIED**, and the game remains **IN DEVELOPMENT**.
