# R2 Known Issues

The cloud environment did not contain Blender, so R2 uses procedural OBJ meshes and Godot StandardMaterial3D resources instead of bundled GLB files. The generated Windows executable was produced successfully from Linux, but real Windows runtime execution is unverified. The workshop and artifact style is intentionally stylized low/mid-poly and is not AAA photorealism. The screenshot evidence covers the implemented flow and is not exhaustive for all 60 ArtifactSpecs.

No known fatal Godot parse error, runtime integration error, missing playable ArtifactSpec model path, duplicate R2 icon hash, zero-byte asset, or failed R2 P0 assertion remains.
